## PayAssured CRM – Agent Guide

The **PayAssured CRM Agent Guide** is designed to help field agents manage their daily field activities, assigned tasks, leads and visit updates directly from the PayAssured CRM mobile application.

Agents can use the app to check in for work, view assigned tasks, accept and start field visits, navigate to customer locations, capture leads, upload photos and documents as evidence, add follow-up notes and complete assigned tasks.

This guide provides simple step-by-step instructions with screenshots to help agents use the application correctly during their day-to-day field activities.

### Agent Guide Covers

* Login to PayAssured CRM
* Enable location and required permissions
* Daily check-in
* View assigned tasks
* Self-assign available tasks
* Accept and start a task
* Navigate to field visit locations
* Add new leads
* Capture leads during field visits
* Add notes and follow-up updates
* Upload photos, documents and visit evidence
* Complete field tasks
* Convert qualified leads and send them to Bigin

**Who should use this guide?** This guide is intended for **Field Agents, Sales Agents and Recovery Agents** who use the PayAssured CRM mobile application for field visits, lead management and assigned work.

> **Important:** Agents should keep location services enabled while performing field tasks and upload the required visit evidence before completing a task.
